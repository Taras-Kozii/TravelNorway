TravelNorway is a modern responsive landing page for a travel company or travel service, focused on showcasing travel destinations and natural locations. The landing page is designed in a minimalist travel-style aesthetic with an emphasis on large visual blocks, typographic hierarchy, and smooth interface interactions.

## 🔗 Live Demo

[TravelNorway](https://taras-kozii.github.io/TravelNorway/)

## 🚀 Core Technologies

- HTML5 — semantic page structure
- CSS3 — styling, responsive layout, and UI animations
- JavaScript (Vanilla JS) — interactivity and interface behavior
- Responsive Web Design (RWD) — adaptation for mobile/tablet/desktop
- Flexbox & CSS Grid — building a modern layout system
- CSS Transitions & Animations — smooth hover effects and transitions
- Git & GitHub Pages — version control and project deployment
